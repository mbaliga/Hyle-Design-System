# Apple platforms (iOS, iPadOS, macOS)

`HyleTokens/` is a Swift package of the Hyle design tokens: plain RGBA colours, `CGFloat`
sizes and integer-millisecond durations, with SwiftUI, UIKit (`uiColor`) and AppKit
(`nsColor`) accessors behind `canImport`. It is generated by `npm run tokens:build` from
`tokens/*.json` and committed; CI regenerates it and fails on drift. Do not edit it by hand.
The older `build/ios/Tokens.swift` output is unchanged.

Status: Swift is not installed in the container this was written in, so nothing here has
been compiled or tested. The `Apple tokens` workflow (`.github/workflows/ios.yml`) is the
first thing that will build it, unsigned, and only while the repo is public. Not built yet:
the Kotlin Multiplatform iOS targets and the Compose-on-iOS harness (blocked on the `:hyle`
KMP decision).

## OWNER_STEPS (your Apple work, later)

Nothing in this repo needs your Apple account yet. When you are ready:

1. Join the Apple Developer Program (OQ-2) and decide the bundle id (NAMES.md row, OQ-25,
   form `com.asoc.<appname>`).
2. Review the `Apple tokens` workflow and pin its actions to commit SHAs.
3. Check the first macOS run: if `swift build` or `swift test` fails, the Swift in
   `scripts/build-tokens.js` needs fixing; if the `xcodebuild` scheme name is wrong, use
   `xcodebuild -list` in `apple/HyleTokens`.
4. Run the package tests on an iPhone and an iPad (Simulator, then a real device).
5. Signing, notarisation (macOS), TestFlight and App Store Connect are all yours; none is
   set up or claimed here, and no signing secret belongs in this repo.

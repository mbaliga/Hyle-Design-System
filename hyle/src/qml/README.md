# Hyle QML tokens (Ubuntu Touch / Qt)

`Hyle/HyleTokens.qml` and `Hyle/qmldir` are generated by `npm run tokens:build` from
`tokens/*.json`. Do not edit them by hand; CI regenerates and fails on drift. They are
template-grade: no QML engine has loaded them here, and rendering on a device is not
verified (no Ubuntu Touch 24.04 device).

## Fonts

No font files are copied into this directory. A click that uses Hyle type must bundle the
families it needs from `fonts/` itself: HyleClassic, HyleDeco, HyleDecoPro,
HyleGroteskClassic, HyleGroteskPlus and HylePrint. Which family a click uses is undecided.

## Licence notice a click must carry

The fonts are under the SIL Open Font License 1.1, each with its own `LICENSE-NOTE.txt`
in its family folder, and are not covered by this repo's Apache-2.0 grant (see `NOTICE`).
Any click that bundles a font must ship that family's `LICENSE-NOTE.txt` and OFL text, and
must not reuse a Reserved Font Name for a modified font (see `TRADEMARKS.md`).
